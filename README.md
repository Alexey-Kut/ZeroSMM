 ZeroSMM — AI-генератор постов для соцсетей

ZeroSMM — это веб-приложение на Flask, позволяющее создавать и публиковать посты во ВКонтакте с помощью нейросетей. Пользователь регистрируется, вводит параметры поста — система генерирует текст и изображение, и при желании публикует это в сообщество VK.

## 🔍 Основные возможности

- 👤 Регистрация и вход в аккаунт
- 📝 Генерация текста поста (через OpenAI ChatGPT)
- 🎨 Генерация изображения (через OpenAI DALL·E 3)
- 📤 Публикация поста в VK через API
- 📊 Статистика по постам (показы, лайки, репосты)
- ⚙️ Управление VK API ID и группой
